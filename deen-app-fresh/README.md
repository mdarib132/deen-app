# দ্বীন — Android অ্যাপ (v0.2)

প্রতিদিনের দোয়া, নামাজ শেখা, ২০টি ছোট সূরা, জিকির কাউন্টার, ফজিলত আর নামাজের সময় ও রিমাইন্ডার — Zimi স্টাইলে, Kotlin + Jetpack Compose দিয়ে।

## APK বানানোর দুই উপায়

### ১. Android Studio দিয়ে (সবচেয়ে সহজ)
1. Android Studio (Koala বা নতুন) ইন্সটল করুন।
2. **File › Open** → এই `deen-app` ফোল্ডার।
3. Gradle sync শেষ হলে ফোন USB দিয়ে লাগিয়ে (Developer options › USB debugging চালু) **Run ▶** চাপুন।
4. শুধু APK চাইলে: **Build › Build App Bundle(s) / APK(s) › Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`

### ২. Android Studio ছাড়া — GitHub দিয়ে
1. GitHub-এ নতুন repo বানিয়ে এই ফোল্ডারটা push করুন।
2. **Actions** ট্যাবে “Build APK” নিজে থেকে চলবে (৫–৮ মিনিট)।
3. শেষ হলে রানের পেজের নিচে **deen-debug-apk** ডাউনলোড করে ফোনে ইন্সটল করুন।

## কনটেন্ট ও যাচাই
- **কুরআনের আরবি:** The Noble Qur’an Encyclopedia (উসমানি লিপি), quran-json 3.1.2 থেকে — `app/src/main/assets/surahs.json`
- **বাংলা অর্থ:** মুহিউদ্দীন খান (Tanzil.net), CC-BY-4.0
- **তিলাওয়াত:** মিশারী রাশিদ আল-আফাসি, everyayah.com থেকে স্ট্রিম
- **বাংলা উচ্চারণ (সূরা ও দোয়া):** হাতে লেখা — **প্রকাশের আগে ছাপা বই বা একজন আলেমের সাথে মিলিয়ে নিন**
- **দোয়া/হাদিস:** `data/Content.kt` — প্রতিটিতে হাদিস নম্বর আছে; Play Store-এ দেওয়ার আগে একবার যাচাই করিয়ে নিন
- **নামাজের সময়:** করাচি পদ্ধতি (১৮°/১৮°), হানাফি আসর ডিফল্ট — স্থানীয় মসজিদের সাথে ১–২ মিনিট পার্থক্য হতে পারে
